# Repository directories

| Path | Purpose |
| --- | --- |
| `a4s/` | Agent runtime, AAS and OPC UA clients, MES adapters, web API |
| `frontend/` | Browser application and Operations interface |
| `BaSyxMinimal/` | Local AAS repository configuration and example blueprints |
| `data/` | Example inputs and application data definitions |
| `docs/` | Setup and user documentation |
| `scripts/` | Local development and maintenance utilities |
| `tests/` | Automated checks |

Runtime state, local configuration and generated outputs should remain outside
version control. See [the tutorial](tutorial.md) for local setup and
[OPC UA connection setup](opc-connection.md) for endpoint configuration.
